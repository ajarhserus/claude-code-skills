# More banned phrases

Same rule as [banned-phrases.md](banned-phrases.md): cut or swap. Do not use these unless quoting a spec or a proper noun.

## More verbs to cut

| Avoid | Use |
| --- | --- |
| surface (verb) | show, return |
| drive (alignment, outcomes) | cause, set |
| deliver value | say what shipped |
| accelerate | speed up, or give the number |
| optimize | name what you change |
| enhance | say the change |
| improve the experience | say the change |
| streamline | name the steps you removed |
| modernize | name the version or tool |
| transform | say the change |
| adopt | start using |
| embrace | use |
| champion | own |
| socialize | tell, send the doc |
| align on | decide |
| land (a change) | ship |
| standup (a service) | start, deploy |
| spin up | start |
| bake in | add, include |
| wire up | connect |
| hook into | call, use |
| tap into | use |
| roll up | sum, group |
| drill down | open, read |
| double down | keep doing X |
| move the needle | name the metric |
| circle back | reply later, or delete |
| touch base | talk |
| reach out | file an issue / page |
| kick off | start |
| wrap one's head around | understand |
| take it to the next level | delete |
| go to market | ship, or name the date |
| productionize | ship |
| industrialize | ship |
| right-size | set the limit |
| instrument | add metric X |
| observe | look at dashboard X |
| remediate | fix |
| mitigate | reduce X by Y |
| ingest | read, load |
| egress | send, write |
| persist | save, write |
| hydrate | load |
| materialize | write, compute |
| encapsulate | hide in X, or just name X |
| abstract away | hide, or name the type |
| expose an API | add `METHOD /path` |
| consume an API | call `METHOD /path` |
| interact with | call, read, write |
| communicate with | call |
| pertaining to | about |
| in order to | to |
| due to the fact that | because |
| for the purposes of | for |
| a number of | N, or some |
| in the event that | if |
| prior to | before |
| subsequent to | after |

## More adjectives and nouns to cut

| Avoid | Use |
| --- | --- |
| actionable | name the action |
| impactful | name the change |
| insightful | delete |
| meaningful | name the number |
| performant | give p99 or cost |
| resilient | name the failure it survives |
| highly available | give the SLO or replica count |
| cloud-native | name AWS/GCP/k8s pieces you actually use |
| enterprise-grade | delete |
| turnkey | list the steps |
| plug-and-play | list the steps |
| zero-touch | name what no one has to do |
| end-to-end | name the start and end |
| full-stack (as praise) | name the parts |
| mission-critical | name who pages |
| world-class | delete |
| industry-leading | delete |
| innovative | delete |
| intelligent / smart (feature) | name the rule |
| dynamic | name what changes |
| magically | delete |
| effortless | delete |
| frictionless | name the step that went away |
| delightful | delete |
| opinionated platform | name the defaults |
| single pane of glass | name the UI |
| source of truth | name the table or file |
| golden path | name the command |
| reference architecture | name the doc |
| design partner | customer name, or delete |
| stakeholder | name the team |
| persona | name the reader |
| artifact | file, image, build |
| solutioning | design |
| learnings | what we found |
| takeaway | the decision |
| blocker | what is stuck and who owns it |
| workstream | the work |
| initiative | the change or the ticket |
| capability | the endpoint or job |
| paradigm | delete |
| methodology | the steps |
| framework (when you mean a doc) | the doc name |
| best practice | what we do here |
| industry standard | name the spec |
| secret sauce | the actual mechanism |
| special sauce | the actual mechanism |
| tribal knowledge | write the fact |
| technical debt (as a shrug) | name the file and the pain |
| big-bang | one deploy, no flag |
| lift and shift | copy as-is to X |
| greenfield / brownfield | new repo / existing repo |
| north-star metric | name the metric |
| 10x | the number you have |
| AI-powered | name the model or delete |
| LLM-powered | name the model |
| agentic | name the job the agent runs |
| copilot experience | the command or UI |
