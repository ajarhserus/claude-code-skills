# Banned phrases and swaps

Cut these. Use the swap or delete the sentence.

## Inflated verbs

| Avoid | Use |
| --- | --- |
| leverage | use |
| utilize | use |
| harness | use |
| facilitate | help, let, make possible |
| orchestrate | run, schedule, coordinate |
| architect (verb) | design, build |
| operationalize | ship, run, turn on |
| ideate | think, sketch |
| empower users to | they can |
| enable customers to | they can |
| provide the ability to | you can |
| serve as a | is |
| act as a | is |
| offer a way to | you can |
| ensure that X | X happens / check X |
| make sure to | do |

## Inflated adjectives

| Avoid | Use |
| --- | --- |
| robust | name the failure it survives |
| seamless | say what the user does not have to do |
| holistic | cover X, Y, Z |
| comprehensive | list what is in scope |
| cutting-edge / state-of-the-art | name the version or paper |
| best-in-class | drop or compare with a number |
| powerful | say what it does |
| flexible | name the knobs |
| scalable | give the number it was tested at |
| intuitive | drop. show the UI or command |
| simple / easy / just | drop. the steps will prove it |
| rich set of | list them |

## Throat-clearing

Delete entire clauses:

- It is important to note that
- It is worth mentioning that
- In today's fast-paced world
- In the ever-evolving landscape of
- As we navigate
- At a high level
- Going forward
- Moving forward
- With that said
- That being said
- Needless to say
- As mentioned above (link or repeat the fact)
- In conclusion (in a README or runbook)
- This document aims to
- The purpose of this document is to
- Welcome to the X documentation
- Here's a comprehensive guide

## Fake togetherness

| Avoid | Use |
| --- | --- |
| our journey | what shipped |
| we are excited to announce | what changed |
| thrilled to share | what changed |
| please do not hesitate to reach out | file an issue / page #oncall |
| feel free to | do X |
| don't hesitate | do X |

## Model tells

Never in shipped docs:

- As an AI language model
- I hope this helps
- Let me know if you need anything else
- Certainly! / Absolutely! / Great question!
- Delve into
- Tapestry / landscape / realm / ecosystem (as decoration)
- Underscores the importance
- Plays a vital role
- Boasts
- Nestled
- Vibrant
- Multifaceted
- Moreover / Furthermore / Additionally as the first word of a paragraph
- Supercharge / unlock / elevate
- Out of the box experience
- Next-generation / game-changer / revolutionize
- Deep dive / dive in / let's unpack
- At its core
- Under the hood (as decoration — name the file)
- Battle-tested
- Production-grade
- Thoughtfully designed
- Opinionated (unless quoting the project)
- First-class support
- Batteries included
- Secret sauce
- North star
- Alignment / aligned stakeholders
- Synergy
- Value-add
- Going forward / moving forward

## Allowed exceptions

- Quote an upstream spec that uses the word.
- A proper noun (`Seamless` the company).
- A user asked for a parody of corporate voice.
